# A header-only implementation of primal-dual algorithms for TV and TGV image denoising

This repository contains a small, header-only implementation for 2D image denoising, using the total variation (TV) and total-generalized variation (TGV) models, using primal-dual optimization. The implementation is given in ```./include/denoise.hpp```.

## Compilation:
The ```./src``` directory contains a .cpp main funtion to read a noisy image, denoise with either TV or the TGV algorithm, and save the output. To compile, first add the [(single-include) nlohmann json parser](https://github.com/nlohmann/json) to the ```include``` folder, following the CMake commands (Visual Studio generator):

```
cmake -S . -B build
cmake --build build --config Release -j
```

## Running
The compiled executable takes a .json configuration file as input. The configuration file contains the following information:

```
{
    "path_image": "path/to/noisy/image",
    "path_output": "filename/denoised/image",

    "model_option": "TGV", // optional: default = TGV

    // optional:
    "parameters": {
        "alpha0": 1.0,       // optional: default = 1.0
        "alpha1: 2.0",       // optional: default = 2.0 - only for TGV model
        "tau": 0.2,          // optional: default = 0.25
        "sigma": 0.2,        // optional: default = 0.25
        "lambda": 0.1,       // optional: default = 0.01
        "niter": 1000,       // optional: default = 1000
        "convergence": 1e-6, // optional: default = 1e-5;
        "verbose": "verbose" // optional: default = "silent"
    }
}
```

Four examples are given in the ```example``` folder: input images of the "ramp" and Shepp-Logan phantom, with TV or TGV denoising. The baseline and noisy examples images can be generated by running the ```./tests/create_images.m``` Matlab\GNU Octave script, storing the images and image dimensions as raw binary files in the ```img``` folder. The denoised images are then generating by running:

```
.\build\Release\tgv-denoise .\example\config_XXX.json
```

## Example: the "ramp" image

The ramp image has a constant gradient throughout the image, with a sharp edge at the boundary of the box. The TV and TGV algorithm were used to denoise the ramp image, with additive Gaussian noise, aiming to reproduce Fig. 1 from [Second Order Total Generalized Variation (TGV) for MRI](https://pmc.ncbi.nlm.nih.gov/articles/PMC4011128/) by Knoll et al.

![ramp](ramp.png)

The TV model introduces the "staircase" artifacts in the denoised image, which are not present when using the TGV model.
